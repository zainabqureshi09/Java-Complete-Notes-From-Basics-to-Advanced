# 🎓 Student Management System (Java)

A simple **console-based Student Management System** built in Java. This project is designed for beginners who want to understand core Java concepts like OOP, ArrayList, loops, and basic CRUD operations.

---

## 🚀 Features

- ➕ Add new student
- 📋 View all students
- 🔍 Search student by ID
- ❌ Delete student by ID
- 🧠 Simple menu-driven console interface

---

## 🛠️ Technologies Used

- Java (Core Java)
- OOP (Object-Oriented Programming)
- ArrayList
- Scanner (User Input)

---

## 📂 Project Structure

```

StudentManagementSystem.java
Student class (inside same file)

````

---

## 🧠 Concepts Covered

This project helps you understand:

- Classes & Objects  
- Encapsulation  
- Constructors  
- ArrayList usage  
- Loops (while, for-each)  
- Switch-case statements  
- Basic CRUD operations  

---

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/student-management-system.git
````

### 2. Navigate to project folder

```bash
cd student-management-system
```

### 3. Compile the program

```bash
javac StudentManagementSystem.java
```

### 4. Run the program

```bash
java StudentManagementSystem
```
